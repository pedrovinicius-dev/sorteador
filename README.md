# 🎲 Sorteador

Programa de linha de comando que sorteia aleatoriamente uma opção entre as inseridas pelo usuário.

## ⚙️ Como funciona

1. O usuário informa quantas opções deseja cadastrar
2. Digita cada opção
3. O programa sorteia uma aleatoriamente

## 🛠️ Linguagem

- C++

## 📌 Exemplo

Escreva o número de opções para sortear: 3
escreva as opções que deseja sortear:
1- Pizza
2- Hamburguer
3- Sushi
a opção sorteada foi: Sushi
